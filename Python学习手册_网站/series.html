🎯 这一套的取舍

为什么是这 7 篇？

因为新手真正会卡住的，只有这几个坎：

  1. 不知道有库这回事（01）
  2. 不知道从哪个库开始（02 / 03）
  3. 不知道怎么把数据弄下来（04）
  4. 不知道怎么写才不出安全事故（05）
  5. 以为 AI 门槛很高（06）
  6. 不知道怎么写才像"会写代码的人"（07）

每篇结构统一：

🎬 场景代入 → 🧠 一句话人话 → 🏠 生活比喻 → 🔧 常用工具速查表 → 🚀 上手代码 → 🐛 坑王榜 → 📌 小结 → 🎯 小作业
