学完 Python 语法就卡住了？你缺的不是知识，是"库"

🎬 场景：你把变量、循环、函数、类都学了一遍，跟着教程写了几个小练习……
然后打开编辑器，发现自己什么都做不出来。
这不是你的问题，是因为没人告诉你：Python 真正的威力，在"库"里。

一、先想明白一件事：语法是工具，库是家具

很多人学 Python 的路径是这样的：

变量 → 循环 → 函数 → 类 → 然后卡住。

因为在大多数教程里，Python 被讲成了一个"数学练习本"：算个阶乘、打印个三角形、写个猜数字游戏。学完你还是不知道它能干嘛。

打个比方：

语法 = 你会用锤子、锯子、螺丝刀。
库 = 一整个成品家具仓库。
你想做个书架，不需要从砍树开始 —— 挑一块现成的板子拼上去就行。

举三个真实的例子，你感受一下"有库"和"没库"的差距：

你想做的事 没库的做法 有库的做法
抓一个网页的数据 自己写 HTTP 协议、处理编码、解析标签 requests + BeautifulSoup ，十行代码
分析一份 5000 行的 Excel 手算 / 写一堆循环 pandas ，一行读出整张表
给 100 张图片加水印 用 PS 一张张点 Pillow ，一个循环搞定

"会不会用库"，基本等于"能不能真的用 Python 干活"。

二、库分两种，先分清楚

标准库 第三方库
是什么 Python 自带的 别人写好、要自己装的
要装吗 不用 要 pip install
例子 json、sqlite3、collections、pathlib、itertools requests、pandas、numpy、openpyxl
优先级 能用的先用它 标准库不够时再装

怎么判断？ 写一行 import xxx 试试：报 ModuleNotFoundError 就是第三方库，需要装。

💡 很多人不知道：Python 自带的标准库已经能解决大量问题（读写文件、JSON、正则、数据库、日期、压缩包、命令行参数……），而且零依赖、不会被版本坑。

三、装库：就一条命令

bash
pip install 库名

常用的几条：

bash
pip install requests              # 装
pip install requests==2.32.3      # 装指定版本
pip install -U requests           # 升级
pip uninstall requests            # 卸载
pip list                          # 看装了什么

国内下载慢？加个镜像源，快 10 倍：

bash
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple

四、虚拟环境：新手最容易忽略、也最该学的一步

先说人话：虚拟环境就是给每个项目一个独立的调料柜。

为什么需要？因为 A 项目要 numpy 1.x、B 项目要 numpy 2.x —— 装在同一个锅里就会打架，报各种莫名其妙的错。

bash
python -m venv .venv          # 在项目文件夹里执行一次
.venv\Scripts\activate        # Windows 激活
source .venv/bin/activate     # macOS / Linux
deactivate                    # 退出

激活成功后，命令行前面会出现 (.venv) 字样 —— 说明你现在在自己的调料柜里。

✅ 记住这一条就够了：每开一个新项目，先建虚拟环境，再 pip install。

🐛 坑王榜 #1：装完了还说找不到

症状：pip install requests 明明成功了，运行还是报 ModuleNotFoundError。

原因：你装到了 A 环境（比如全局 Python），但运行代码用的是 B 环境（比如编辑器选的另一个解释器）。

怎么修：

  1. 看一眼终端前面有没有 (.venv)
  2. VS Code 里按 Ctrl+Shift+P → 输入 Python: Select Interpreter → 选中你的 .venv

五、报错怎么看：这一步学会，能省一半时间

Python 的报错信息从下往上看：

text
Traceback (most recent call last):
  File "test.py", line 3, in <module>
    print(1 / 0)
ZeroDivisionError: division by zero
  • 最后一行 = 错在哪类（ZeroDivisionError = 除以 0）
  • 倒数第二行 = 错在哪一行（line 3）
  • 中间的 File "xxx", line N = 出错的文件和位置

新手最常遇到的 6 个报错，建议截图存下来：

报错 人话翻译 怎么改
ModuleNotFoundError: No module named 'requests' 没装这个库 pip install requests（注意在正确的环境里）
NameError: name 'df' is not defined 变量名写错 / 还没定义 检查拼写和顺序
TypeError: can only concatenate str (not "int") to str 字符串和数字相加了 用 str(数字) 转一下
IndentationError 缩进错了 统一用 4 个空格，别混 Tab
KeyError: 'xxx' 字典里没这个键 用 d.get("xxx", 默认值)
AttributeError: 'NoneType' object has no attribute ... 上一步返回了 None，你还接着用它 往上一行找，看哪个函数没返回东西

六、三个"马上能看到效果"的库，先找点成就感

学东西最怕没反馈。先玩这三个，你会立刻觉得"值了"：

1️⃣ 用 openpyxl 生成一张 Excel

bash
pip install openpyxl
python
from openpyxl import Workbook, load_workbook

wb = Workbook()
ws = wb.active
ws.title = "成绩"

ws.append(["姓名", "分数", "评价"])
for name, score in [("张三", 686), ("李四", 655)]:
    ws.append([name, score, "优秀" if score >= 660 else "良好"])

wb.save("成绩表.xlsx")

# 读回来验证
wb2 = load_workbook("成绩表.xlsx")
for row in wb2["成绩"].iter_rows(values_only=True):
    print(row)

你会看到（实测）：

text
('姓名', '分数', '评价')
('张三', 686, '优秀')
('李四', 655, '良好')

这里面发生了什么：ws.append([...]) 就是"往表格里追加一行"；wb.save() 落盘。

建议立刻改一改：加一行自己名字，把"优秀"的门槛改成 680。

2️⃣ 用 Pillow 给图片加字

bash
pip install pillow
python
from PIL import Image, ImageDraw, ImageFont

img = Image.new("RGB", (300, 120), "#4f81bd")       # 新建一张蓝色图
d = ImageDraw.Draw(img)
font = ImageFont.truetype("C:/Windows/Fonts/msyh.ttc", 28)   # ★ 中文必须指定字体
d.text((30, 40), "你好 Python", font=font, fill="white")
img.save("我的图.png")
print("生成成功，尺寸:", Image.open("我的图.png").size)

你会看到：生成成功，尺寸: (300, 120)

3️⃣ 用 qrcode 生成二维码

bash
pip install "qrcode[pil]"
python
import qrcode
qrcode.make("https://github.com/chenhg5/cc-connect").save("我的二维码.png")
print("二维码已生成")
🎯 这三个库的共同点：装了 → 复制 → 跑 → 看得见结果。这就是正反馈。

七、数据处理三件套（预告）

有了成就感，就该学"真正能解决问题"的东西了。下一节我们讲让数字自己算：

  • numpy —— 批量数值计算，不写循环
  • pandas —— Python 里的 Excel，筛选/分组/统计
  • matplotlib —— 把数字画成图

先给你看一个 pandas 的片段，感受一下：

python
import pandas as pd

df = pd.DataFrame({"姓名": ["张三", "李四", "王五"], "分数": [686, 655, 700]})
print(df[df["分数"] >= 680])      # 按条件筛选
print("平均分:", round(df["分数"].mean(), 1))

你会看到（实测）：

text
   姓名   分数
0  张三  686
2  王五  700
平均分: 680.3

就两行代码，完成了"按条件筛选 + 求平均"。如果手写循环，至少要 8 行。

🧰 附：本文出现过的库 · 常用工具速查

小白最缺的不是"知道有这个库"，而是"打开编辑器不知道敲什么"。
下面这几张表，直接照着抄就能跑。

📦 pip（装库）

工具 干什么 典型写法
pip install 库名 装库 pip install requests
pip install 库名==版本 装指定版本 pip install pandas==2.2.0
pip install -U 库名 升级 pip install -U pip
pip list 看装了哪些库 pip list（想只看某个库，配合 findstr 名字）
pip uninstall 库名 卸载 pip uninstall requests
pip install -r requirements.txt 按清单装齐 换电脑时最有用
镜像加速 国内下载慢时加 -i https://pypi.tuna.tsinghua.edu.cn/simple

📊 openpyxl（写 Excel）

工具 干什么 典型写法
Workbook() 新建工作簿 wb = Workbook()
wb.active 拿到当前表 ws = wb.active
ws.title = "名字" 给表改名 ws.title = "成绩"
ws.append([...]) 一行一行写（最常用） ws.append(["张三", 686])
ws["A1"] = 值 按单元格写 ws["D1"] = "=SUM(B2:B3)"
Font(bold=True) / PatternFill() 加粗 / 底色 表头美化
ws.column_dimensions["A"].width 调列宽 不然中文挤成一团
ws.freeze_panes = "A2" 冻结首行 滚动时表头不动
load_workbook() 读回来 ws.iter_rows(values_only=True)
wb.save("x.xlsx") 保存 别忘了这一步

🖼 Pillow（改图片）

工具 干什么 典型写法
Image.open("a.jpg") 打开图片 支持 jpg/png/webp…
Image.new("RGB", (w,h), 颜色) 新建空白图 做底图
img.resize((400,300)) 改尺寸 img.thumbnail((128,128)) 是按比例缩
img.rotate(90, expand=True) 旋转 expand 防止裁掉
img.convert("L") 转灰度 还有 "RGB"
ImageDraw.Draw(img).text(...) 加文字 中文要指定 ImageFont.truetype
img.filter(ImageFilter.GaussianBlur(2)) 模糊 马赛克/模糊背景
img.save("b.png") 保存（可换格式） jpg → png 直接改后缀

🔳 qrcode（生成二维码）

工具 干什么 典型写法
qrcode.make(内容) 一行生成 qrcode.make("https://…")
.save("x.png") 存成图片 扫码即可
QRCode(version, box_size, border) 精细控制 调大小、边距
add_data() + make() 分步生成 需要改颜色时用
pyzbar.decode(图片) 反向识别二维码 读别人图里的码
