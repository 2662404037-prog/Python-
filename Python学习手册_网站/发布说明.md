# 网站发布说明（Netlify）

这个文件夹就是一个**完整的静态网站**，而且已经**配好了 Netlify**：
`netlify.toml`（发布目录 / 缓存 / 安全头 / 短链接）、`_redirects`、`404.html`、`robots.txt`、`sitemap.xml`。

## 最快的两种发布方式

**① 拖一下（30 秒，不用装任何东西）**
打开 https://app.netlify.com/drop → 把**整个文件夹**拖进去 → 拿到网址。

**② 双击部署（以后更新也用它）**
双击本目录的 **\`部署到Netlify.cmd\`**：
第一次会让你在浏览器里授权登录，然后自动 `deploy --prod`；
以后内容改了，再双击一次就完成更新。

> 需要 Node.js（`cmd` 会自己检查，没有会提示你去 nodejs.org 装 LTS 版）。

## 方式一：Netlify Drop（最简单，30 秒，不用注册也能试）

1. 浏览器打开 **https://app.netlify.com/drop**
2. 把 **整个 `Python学习手册_网站` 文件夹**拖进去
3. 等几秒 → Netlify 会给你一个网址，形如 `https://xxxx-yyyy.netlify.app`
4. 想改名字：登录后进 **Site configuration → Change site name**

> ⚠️ 拖拽时**拖文件夹本身**，不要只拖里面的文件。

## 方式二：用命令行发布（可反复更新）

需要先登录（会打开浏览器让你授权）：

```bash
# 1. 安装 Netlify CLI（任选一种）
npm i -g netlify-cli
# 或者不安装直接用：
npx netlify-cli --version

# 2. 登录（会打开浏览器）
netlify login

# 3. 在站点目录里初始化并发布
cd "Python学习手册_网站"
netlify init          # 选 "Create & configure a new site"
netlify deploy --prod --dir=.
```

以后内容更新了，只要再跑一次：

```bash
netlify deploy --prod --dir=.
```

## 方式三：接到 GitHub（每次 push 自动部署）

1. 把 `Python学习手册_网站` 文件夹推到一个 GitHub 仓库
2. Netlify → **Add new site → Import an existing project** → 选这个仓库
3. Build command 留空，**Publish directory 填 `.`**（或填文件夹名）
4. 之后每次 push，Netlify 自动重新部署

## 内容更新后怎么重新生成

改了 Markdown 之后，用工具重新生成网站：

```bash
python 工具/md2site.py "Python学习手册_网站" ^
  "Python常用库入门教程_初学者版.md|tutorial|入门教程" ^
  "常用第三方库速查.md|reference|库速查" ^
  "爬虫实战教程.md|spider|爬虫实战" ^
  "知识点文案.md|basics|知识点" ^
  "公众号文章_Python常用库全解读.md|wechat|公众号文章"
```

（Windows 换行符用 `^`，macOS/Linux 用 `\`）

> 注意：重新生成只会覆盖 5 个 html 和 assets，**不会动 index.html 和 downloads/**。

## 常见问题

**Q：直接双击 index.html 能看吗？**
能，但目录高亮、复制代码这些功能在 `file://` 下可能受限，建议发布后再看。

**Q：能放自己的域名吗？**
可以，Netlify 免费额度就支持自定义域名 + 自动 HTTPS。

**Q：中文文件名会不会有问题？**
页面文件名我特意用了英文（`tutorial.html` 等），只有 `downloads/` 里的 PDF 是中文名——Netlify 会自动做 URL 编码，能正常下载。如果你想更保险，可以把 PDF 改成英文名再更新首页链接。
