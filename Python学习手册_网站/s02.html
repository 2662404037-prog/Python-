Python 数据处理三件套：让数字自己算

🎬 场景：老板发来一个 5000 行的 Excel，让你"统计一下每个城市的平均分，顺便画个图"。
你打开 Excel 开始手动筛选……半小时后，老板说："数据更新了，重新算一遍。"
这篇讲三个库，让你把这件事变成 10 行代码、5 秒出结果。

一、numpy：让数字"整体"运算

先看一个反直觉的现象

python
普通列表 = [1, 2, 3, 4]
print(普通列表 * 2)

输出是：

text
[1, 2, 3, 4, 1, 2, 3, 4]

列表乘以 2 等于"重复两遍"，不是每个数乘 2。这就是为什么需要 numpy。

它是什么

numpy 给 Python 加了一种新容器：数组（array）。它的核心特点是 —— 整体运算。

bash
pip install numpy
python
import numpy as np

a = np.array([1, 2, 3, 4])
print("整体乘 2:", a * 2)
print("均值/最大:", a.mean(), a.max())

m = np.arange(6).reshape(2, 3)      # 0~5 排成 2 行 3 列
print("2x3 矩阵:")
print(m)
print("每列求和:", m.sum(axis=0))

实测输出：

text
整体乘 2: [2 4 6 8]
均值/最大: 2.5 4
2x3 矩阵:
[[0 1 2]
 [3 4 5]]
每列求和: [3 5 7]

逐行解释

  • np.array([1,2,3,4]) —— 把列表变成数组，这是 numpy 的基本单位
  • a * 2 —— 每个元素都乘 2（对比上面列表的行为）
  • a.mean() / a.max() —— 直接求平均、求最大，不用写循环
  • np.arange(6) —— 生成 0,1,2,3,4,5
  • .reshape(2,3) —— 把它排成 2 行 3 列
  • .sum(axis=0) —— 沿"第 0 轴"求和 = 每列的和（改成 axis=1 就是每行）
💡 一句话记住：numpy 快，是因为它不写 for 循环。

🎯 动手改一改

  1. 把 a * 2 改成 a + 100、a ** 2（平方）
  2. 把 .reshape(2,3) 改成 .reshape(3,2)
  3. 把 axis=0 改成 axis=1

为什么要会这些：numpy 是 pandas、OpenCV、PyTorch 的共同底层。学会它，后面那些库都顺手。

二、pandas：Python 里的 Excel

它是什么

pandas 把数据变成带表头的表格（叫 DataFrame），然后你就能像在 Excel 里那样筛选、排序、分组、统计 —— 只是全部用代码，而且能处理几十万行。

bash
pip install pandas openpyxl

最小可用例子

python
import pandas as pd

df = pd.DataFrame({
    "姓名": ["张三", "李四", "王五"],
    "分数": [686, 655, 700],
    "城市": ["杭州", "武汉", "北京"],
})
print(df)
print("平均分:", round(df["分数"].mean(), 1))
print("筛选 >=680:")
print(df[df["分数"] >= 680][["姓名", "分数"]])
print("按城市分组均值:", df.groupby("城市")["分数"].mean().to_dict())

实测输出：

text
   姓名   分数  城市
0  张三  686  杭州
1  李四  655  武汉
2  王五  700  北京
平均分: 680.3
筛选 >=680:
   姓名   分数
0  张三  686
2  王五  700
按城市分组均值: {'北京': 700.0, '杭州': 686.0, '武汉': 655.0}

逐行解释

  • pd.DataFrame({...}) —— 把字典变成表格；字典的键变成表头
  • df["分数"].mean() —— 选出"分数"这一列求平均
  • round(x, 1) —— 保留 1 位小数
  • df[df["分数"] >= 680] —— 按条件筛选行，这是 pandas 的灵魂，先记住这个形状
  • [["姓名", "分数"]] —— 只要这两列
  • groupby("城市") —— 按城市分组，算"每个城市的平均分"

四个你会用到 90% 时间的方法

想干什么 写法
求平均 / 最大 df["列"].mean() / df["列"].max()
数每个值出现几次 df["列"].value_counts()
按某列分组统计 df.groupby("列")["另一列"].mean()
按条件筛选 df[df["列"] > 值]

🐛 坑王榜 #2：中文导出全是乱码

症状：df.to_csv("成绩.csv") 之后，用 Excel 打开全是乱码。

原因：Excel 默认用 GBK 打开 CSV，而 pandas 写的是 UTF-8。

怎么修：

python
df.to_csv("成绩.csv", index=False, encoding="utf-8-sig")   # ★ 加这个

utf-8-sig 会多写一个 BOM，Excel 就认得出来了。

三、matplotlib：把数字画成图

它是什么

把数据画成折线、柱状、散点、直方图，然后导出成图片放进报告或论文。

bash
pip install matplotlib
python
import matplotlib
matplotlib.use("Agg")                     # 只保存文件，不弹窗（脚本必备）
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]   # ★ 中文不乱码
plt.rcParams["axes.unicode_minus"] = False              # ★ 负号不乱码

fig, ax = plt.subplots(figsize=(4, 3))
ax.bar(["张三", "李四", "王五"], [686, 655, 700], color="#4f81bd")
ax.set_title("三个人考了多少分")
ax.set_ylabel("分数")

plt.savefig("chart.png", dpi=120, bbox_inches="tight")
plt.close(fig)
print("图已保存")

实测输出：

text
已保存: chart_demo.png  大小: 13125 字节

三个必踩的坑（我都踩过）

坑 症状 怎么修
中文变方框 标题是一排 □□□ plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]
保存的图是空白 打开图片全白 savefig 必须写在 plt.show() 之前
服务器上报错 提示找不到显示设备 开头加 matplotlib.use("Agg")

换个图形只改一个词

想要的图 写法
柱状图 ax.bar(标签, 数值)
折线图 ax.plot(x, y)
散点图 ax.scatter(x, y)
直方图（看分布） ax.hist(一堆数字, bins=20)

四、把三个库串起来：一个真实小任务

任务：读一个 CSV，算平均分，画一张图。

python
import pandas as pd
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]

# ① 读数据
df = pd.read_csv("成绩.csv")

# ② 算
print("平均分:", round(df["分数"].mean(), 1))
print("最高的三个:")
print(df.nlargest(3, "分数")[["姓名", "分数"]])

# ③ 画
fig, ax = plt.subplots(figsize=(5, 3))
ax.bar(df["姓名"], df["分数"], color="#4f81bd")
ax.axhline(df["分数"].mean(), color="red", linestyle="--", label="平均线")
ax.set_title("成绩对比"); ax.legend()
plt.savefig("成绩图.png", dpi=120, bbox_inches="tight")
print("图已保存")

这段代码干完的活：原本要手动筛选 + 算平均 + 做成图表，现在一次运行 2 秒。

🧰 附：本文库的「常用工具速查」

这三张表建议贴在编辑器旁边。90% 的数据处理，用到的就是这些。

🔢 numpy

工具 干什么 典型写法
np.array(列表) 列表 → 数组 一切的开始
整体运算 每个元素一起算 a * 2、a + 10、a ** 2
a.mean() / a.sum() / a.max() / a.min() 统计四件套 不用写循环
a.sum(axis=0) 按列求和 axis=1 是按行
np.arange(n) 生成 0~n-1 配合 reshape
.reshape(行, 列) 变成矩阵 np.arange(6).reshape(2,3)
a[a > 5] 按条件筛选 比 pandas 还快
np.linspace(0, 1, 5) 等间隔数列 画图常用
np.random.rand(3) 随机数 造测试数据

🐼 pandas

工具 干什么 典型写法
pd.DataFrame({...}) 造表 字典的键变表头
pd.read_csv() / read_excel() 读文件 加 encoding="utf-8-sig" 读中文 CSV
df.head() / df.info() / df.shape 先看一眼数据 拿数据集第一件事
df["列"] 取一列 df[["A","B"]] 取多列
df[df["分数"] > 660] 筛选行（灵魂） 多条件用 & 和「或」符号连接（记得加括号）
df.mean() / sum() / max() 统计 可对整表或单列
df.value_counts() 数出现次数 看分布最快
df.groupby("列").mean() 分组统计 最常用的一招
df.sort_values("列", ascending=False) 排序 排行榜
df.dropna() / fillna(0) 处理空值 数据清洗必用
df.to_excel("x.xlsx", index=False) 导出 加 index=False 去掉行号

📈 matplotlib

工具 干什么 典型写法
plt.plot(x, y) 折线图 趋势
plt.bar(标签, 值) 柱状图 对比
plt.hist(数据, bins=20) 直方图 看分布
plt.scatter(x, y) 散点图 看相关性
plt.pie(值, labels=标签) 饼图 占比
plt.title/xlabel/ylabel 标题 / 轴名 中文要先设字体
plt.rcParams["font.sans-serif"] 设中文字体 ["Microsoft YaHei"]
plt.legend() / grid(True) 图例 / 网格 别忘加
plt.savefig("x.png", dpi=150, bbox_inches="tight") 保存 必须在 show 之前

📌 这篇你学到了

  • numpy：整体运算，不写循环（它还是其他库的底层）
  • pandas：筛选 df[条件]、统计 .mean() .value_counts() .groupby()
  • matplotlib：画图 + 中文显示 + savefig 顺序两个必踩的坑
  • 导出 CSV 一定要 .to_csv(..., encoding="utf-8-sig")
