一、五种数据容器：什么时候用哪个

这是本次作业真正的考点。判断口诀：要顺序用 list / tuple，要唯一用 set，要"按名字查东西"用 dict。

容器 写法 三个关键词 本次作业用在哪
list 列表 [1, 2, 3] 有顺序、能改、可重复 wish_list 志愿表、task_list 任务清单、选科
tuple 元组 (1, 2, 3) 有顺序、不能改、可重复 universities（分数线是"事实"，不该被随手改）
str 字符串 "张三" 文字、不可变 student["姓名"]
set 集合 {1, 2, 3} 自动去重、无序、元素必须可哈希 兴趣标签去重、志愿表查重、推荐专业去重
dict 字典 {"键": "值"} 按 key 找 value student、major_map、专业计数

两个容易忘的细节：

  1. list 和 tuple 唯一的根本区别：能改 / 不能改。

试试 universities[0][2] = 700 → 直接报错，这就是题目让你"体会"的地方。

  1. set 里不能放 list。set([[1,2],[3,4]]) 会报 TypeError: unhashable type: 'list'。

原因见 3.3 —— 集合靠"哈希值"判断元素是否重复，而可变容器没法安全地哈希。

二、我踩过的 12 个坑

🕳️ 坑 1：链式比较 —— interest in major_map == True

现象：推荐专业那一栏永远是空的，程序不报错，就是没结果。

python
if interest in major_map == True:      # ❌ 永远为 False
    recommended.append(interest)

为什么错：Python 允许链式比较，a < b < c 会被理解成 (a < b) and (b < c)。

in 也是比较运算符，所以上面那行实际是：

python
(interest in major_map) and (major_map == True)
#                                 ↑ 字典永远不等于 True

结果永远是 False。实测：'计算机' in major_map == True → False，而 '计算机' in major_map → True。

正确写法：

python
if interest in major_map:              # 直接写条件
    ...

一句话记住：永远不要写 == True。if 条件: 本身就是"如果条件为真"。

🕳️ 坑 2：pop + 下标自增 → 每删一个就跳过一个

现象：想把 task_list 清空，结果只删掉一半，剩下 ['查询大学', '提交志愿']。

python
i = 0
while i < len(task_list):
    task_list.pop(i)     # ❌
    i += 1

为什么错：pop(i) 删掉一个元素后，后面的元素会集体往前挪一格，但 i 又往前走了，于是正好跳过下一个。手推一遍：

步骤 列表 说明
开始 [整理成绩, 查询大学, 筛选专业, 提交志愿] i=0
第 1 轮后 [查询大学, 筛选专业, 提交志愿] pop(0) 删掉"整理成绩"，i 变 1
第 2 轮后 [查询大学, 提交志愿] pop(1) 删掉"筛选专业"，i 变 2
结束 [查询大学, 提交志愿] len 只剩 2，i=2 不满足条件

正确写法（题目提示给了）：永远删第 0 个

python
while len(task_list) > 0:      # 或者写成 while task_list:
    task_list.pop(0)

一句话记住：边遍历边删除时，下标会"骗"你。

🕳️ 坑 3：print ≠ return（最致命的一个）

现象：result = progress_function(0.05, final_analysis) 之后 print(result) 打出的是 None，精心写的报告一个字都没出现。

python
def progress_function(sleep_time, print_function):
    for x in range(100):
        ...
    sleep(0.1)
    if x == 99:
        print_function()      # ❌ 执行了，但返回值直接丢了
                              # 函数最后没有 return → 返回 None

为什么错：没有 return 的函数，返回值就是 None。

  • print(x) = 在屏幕上显示 x，函数返回值还是 None
  • return x = 把 x 交给调用者，可以被 = 接住

final_analysis() 确实被调用了、也算出了报告字符串，但没人接住 → 被扔掉了。

正确写法：

python
return print_function()      # 接住回调的返回值，再交出去

一句话记住：想让外面接到东西，就必须 return；print 只是给人看的。

🕳️ 坑 4：append 和 extend 分不清 / 存错了东西

现象：推荐专业里存的是"计算机"这种兴趣标签，而不是"计算机科学与技术"这种专业。

python
recommended_majors.append(interest)                   # ❌ 存了标签
recommended_majors.extend(major_map[interest])        # ✅ 存了专业

区别：

python
a = []
a.append(["计算机科学与技术", "软件工程"])   # → [['计算机科学与技术', '软件工程']]  整个列表塞进去
a.extend(["计算机科学与技术", "软件工程"])   # → ['计算机科学与技术', '软件工程']   拆开逐个塞

一句话记住：append 塞一个东西，extend 把里面的东西逐个塞进去。

🕳️ 坑 5：把"整张表的判断"写在 for 循环里面

现象：程序连打 5 遍"志愿表中没有重复的大学名称"。

python
for i in range(len(wish_list)):
    if 有重复:                 # ❌ 每所大学都判一次、打一次
        print("志愿表中存在重复大学")

为什么错：题目要判断的是"整张志愿表有没有重复"，一次就够，所以要跳出循环再判。

正确写法：

python
names = [item[0] for item in wish_list]
if len(set(names)) == len(names):      # 循环之外，只判一次
    print("志愿表中没有重复大学")
else:
    print("志愿表中存在重复大学")

一句话记住：循环负责"收集数据"，判断和输出放在循环外面。

🕳️ 坑 6：拿"自己和自己比"，条件恒为真

现象：不管资料里有没有重复，永远输出"没有重复"。

python
if list(set(wish_list[i][0])) == list(set(wish_list[i][0])):   # ❌ 左右完全一样

为什么错：等号两边是同一个东西，永远相等。我本来想比较"原始"和"去重后"，但两边都写了去重版。

正确的查重思路 —— 比"去重前后的个数"：

python
len(set(names)) == len(names)
  • 5 个名字 → 放进 set → 还剩 5 个 → 一个都没被去掉 → 没重复
  • 5 个名字 → 放进 set → 变成 4 个 → 有 2 个一样 → 有重复

一句话记住：查重 = len(set(x)) 和 len(x) 比大小。

🕳️ 坑 7：print 写在 for 外面 → 只打印最后一个

现象：专业计数只输出了一行 专业 电子信息工程: 出现 2 次，其他专业都消失了。

python
for i in range(len(wish_list)):
    for major in wish_list[i][1]:
        major_count[major] = major_count.get(major, 0) + 1
print(f"专业 {major}: 出现 {major_count[major]} 次")     # ❌ 在循环外！

为什么错：统计部分其实是对的，但打印跑出了循环，所以只在最后打印了一次，用的还是循环结束时残留的那个 major。

正确写法 —— 用 for 遍历字典：

python
for major in major_count:
    print(major, "出现了", major_count[major], "次")

一句话记住："每一个"要打印 → print 必须在 for 里面。

🕳️ 坑 8：函数写了参数，却根本没用

现象：analyze_student(student, universities) 看起来没问题，但函数体里从来没用过这两个参数。

python
def analyze_student(student, universities):
    return challenge_list, safe_list, not_recommended_list   # ❌ 用的是外面的全局列表

为什么错：参数是函数的"输入"。函数应该"给我什么，我算什么"，而不是偷偷去读外面的全局变量。否则这个函数换个学生、换份学校表就完全没用了。

正确写法 —— 用参数，在函数内部新建列表：

python
def analyze_student(student, universities):
    challenge, safe, not_recommended = [], [], []
    for name, _city, line in universities:
        if student["高考分数"] >= line:
            safe.append(name)
        elif student["高考分数"] >= line - 10:
            challenge.append(name)
        else:
            not_recommended.append(name)
    return challenge, safe, not_recommended

另一个隐藏问题：直接返回全局列表时，外面任何地方改了那个列表，"函数返回的结果"也会跟着变（它们是同一个对象，原理见 3.2）。

一句话记住：函数只认参数，不认全局。

🕳️ 坑 9：任务 4 用切片代替了 for 循环

现象：题目要求"使用 for 循环倒序复制，并且子列表也要倒序"，我写的是 new_list = my_list[::-1]。

为什么错：

  • 题目写"必须使用 for 循环"——这是考点，用了切片直接不给分
  • my_list[::-1] 只能把外层倒过来，里面的 ["计算机","机器人","自动化"] 还是原顺序，没满足"子列表也倒序"

正确思路：外层用 range 倒着走，碰到子列表再用切片倒一次。

python
new_list = []
for i in range(len(my_list) - 1, -1, -1):     # 外层：整体倒序
    item = my_list[i]
    if isinstance(item, list):                # 判断是不是列表
        new_list.append(item[::-1])           # 子列表也倒序
    else:
        new_list.append(item)

一句话记住：作业里写"必须用 X"的地方，就用 X，别用更聪明的写法。

🕳️ 坑 10：range 的"左闭右开"没搞清

现象：倒着遍历时少走了一格 / range 的终点写错。

规则：range(起点, 终点, 步长)，包含起点，不包含终点。

python
range(5)            # 0 1 2 3 4
range(2, 5)         # 2 3 4          终点 5 取不到
range(0, 10, 2)     # 0 2 4 6 8
range(4, -1, -1)    # 4 3 2 1 0      倒着走

所以倒着遍历全部下标要写 range(len(x) - 1, -1, -1)：

  • 起点 len-1 = 最后一个下标
  • 终点写 -1（因为右开，走到 -1 才会包含 0）
  • 步长 -1 = 每次减 1

一句话记住：终点取不到，所以倒着走要写到 -1。

三、知识点详解（进阶篇）

3.1 可变 vs 不可变 —— Python 最底层的一条分界线

不可变类型（immutable）：int、float、str、tuple、bool、frozenset、None

可变类型（mutable）：list、dict、set、bytearray

"不可变"到底是什么意思？

不是"你不能改"，而是"它不允许被原地修改"——你只能造一个新的对象，把变量名重新指过去。

python
s = "abc"
s[0] = "A"          # ❌ TypeError: 'str' object does not support item assignment

s = s + "d"         # ✅ 这句话其实是"新建了 abcd 这个新字符串"，再让 s 指向它
python
t = (1, 2, 3)
t[0] = 9            # ❌ TypeError: 'tuple' object does not support item assignment

lst = [1, 2, 3]
lst[0] = 9          # ✅ 列表可以原地改
lst.append(4)       # ✅ 原地追加

怎么自己验证一件事会不会"原地改"？

用 id() 看内存地址，变没变一目了然：

python
lst = [1, 2, 3]
print(id(lst))      # 比如 140234...
lst.append(4)
print(id(lst))      # 地址**没变** → 原地修改（mutable）

s = "abc"
print(id(s))
s = s + "d"
print(id(s))        # 地址**变了** → 新建了对象（immutable）

Python 为什么要这样设计？

因为不可变 = 安全 = 可以当"标签"用。回想坑 1 的 set：集合和字典的 key 都要求"可哈希（hashable）"，而可哈希的前提就是不可变。如果 list 能当 set 的元素，你往列表里加个东西，集合里存的"标签"就失效了。所以 Python 干脆禁止。

对本作业的意义：universities 用 tuple 装，就是想表达"这些录取分数线是既定事实，代码里不应该修改它"。这是一种"用类型表达意图"的写法。

3.2 变量是"名字"，不是"盒子" —— 引用、is、拷贝

这是初学者最容易误解的一点。在 Python 里，变量不装值，变量只是贴在对象上的一个名字。

python
a = [1, 2, 3]

写法 比较的是 例子
a == b 值是否相等 [1,2] == [1,2] → True
a is b 是不是同一个对象（地址相同） [1,2] is [1,2] → False

y = [1, 2]

print(x is y)          # False  两个不同的列表对象

💡 一句话：is 问"是不是本人"，== 问"长得一样吗"。
只有判断 None 才习惯用 is：if x is None:

怎么真正"复制"一份？

python
a = [1, 2, 3]

b = a              # ❌ 只是别名，不复制
b = a.copy()       # ✅ 浅拷贝
b = list(a)        # ✅ 另一种浅拷贝

⚠️ 浅拷贝的坑：里层不复制

b[0] = 99

b[2].append(5)
print(a)              # [1, 2, [3, 4, 5]]   ← 里层共享！a 也变了

真要把里层也复制干净，得用深拷贝：

python
import copy
b = copy.deepcopy(a)    # 从里到外全部复制一份

顺便：is 的一个记忆陷阱

Python 对小整数（-5~256）和短字符串做了缓存，所以偶尔会出现：

3.7 比较运算符与链式比较

3.9 切片（slicing）完全指南

写法：容器[起点 : 终点 : 步长]，左闭右开，三个都可以省略。

python
lst = ["a", "b", "c", "d", "e"]

lst[1:3]      # ['b', 'c']        从 1 到 3（不含 3）
lst[:2]       # ['a', 'b']        省略起点 = 从头开始
lst[2:]       # ['c', 'd', 'e']  省略终点 = 到末尾
lst[:]        # 整个列表的"浅拷贝"
lst[-2:]      # ['d', 'e']        负数下标：从倒数第 2 个到末尾
lst[:-2]      # ['a', 'b', 'c']  去掉最后两个

lst[::-1]     # ['e','d','c','b','a']   倒序 ← 本作业常用
lst[::2]      # ['a', 'c', 'e']         隔一个取一个
lst[4:1:-1]   # ['e', 'd', 'c']         倒着取

几个要点：

  1. 字符串也能切片："张三丰"[1:] → "三丰"
  2. 切片越界不报错，会自动截断：lst[0:100] → 整个列表
  3. 但普通下标越界会报错：lst[100] → IndexError
  4. [::-1] 是倒序的经典写法，但本作业任务 4 / 挑战 2 明确要求用 for + range，别用切片

3.12 边遍历边修改 —— 一个必须警惕的操作

坑 2 的本质。看这个"看起来没问题"的写法：

python
lst = ["a", "b", "c", "d"]
for x in lst:
    if x in ("a", "b"):
        lst.remove(x)
print(lst)          # ['b', 'd']  ← 不是期待的 ['c', 'd']！

为什么：for 内部是按下标往前走的；你删掉一个元素，后面的元素集体前移，序号就错位了。

三种正确做法：

python
# ① 遍历"副本"，改的却是原列表
for x in lst[:]:
    lst.remove(x)

# ② 倒着遍历（倒着删不会影响还没处理的下标）
for i in range(len(lst) - 1, -1, -1):
    if 条件:
        lst.pop(i)

# ③ 直接重新构造（最推荐，最不容易错）
lst = [x for x in lst if not 条件]

一句话：要删东西，就倒着遍历，或者遍历副本，或者重建列表。

3.16 默认参数的陷阱（进阶，知道就好）

python
def add_item(x, lst=[]):     # ❌ 危险！默认值只在定义时创建一次
    lst.append(x)
    return lst

print(add_item(1))    # [1]
print(add_item(2))    # [1, 2]   ← 咦？它不是应该重新开始吗？

原因：默认参数 [] 是在函数定义时创建的同一个列表，被多次调用共享。

正确写法：用 None 当默认值，在函数里面再创建。

python
def add_item(x, lst=None):
    if lst is None:
        lst = []
    lst.append(x)
    return lst

3.17 常见报错速查表（看报错不再发懵）

Python 的报错信息从下往上看：最后一行是"错误类型 + 原因"，倒数第二行是"出错的文件和行号"。

报错 中文意思 常见原因 怎么修
SyntaxError 语法错误 少了冒号 :、括号 / 引号不配对 看它标的位置前一行
IndentationError 缩进错误 该缩进没缩进，或者空格/Tab 混用 统一用 4 个空格
NameError 名字不存在 变量名拼错、变量还没定义就用了 检查拼写；确认赋值在调用之前
TypeError 类型不对 "年龄" + 18、len(123)、unhashable type: 'list' 先 str() / int() 转换；set/dict 别放 list
ValueError 值不对 int("abc")、"1,2".split(",") 用法错 检查内容格式
IndexError 下标越界 lst[5] 但列表只有 3 个元素 用 len(lst) 检查范围
KeyError 字典没有这个键 d["不存在的键"] 先用 in 判断，或用 d.get(键, 默认值)
AttributeError 对象没有这个属性/方法 方法名拼错（lst.apppend()），或类型不对 检查拼写、检查对象类型
ZeroDivisionError 除以 0 10 / 0 加判断
UnboundLocalError 局部变量还没赋值就用 函数里既赋值又读同名全局变量 见 3.14 作用域

读报错的固定动作：看最后一行知道"错在哪类"，看倒数第二行知道"错在哪一行"，然后去那一行。

3.18 调试五步法

八、常用用法备注（按类型速查）

这一节是"平时写代码时最常忘的那些点"。符号含义：
✅ 推荐这么写　⚠️ 要注意　❌ 别这么写

8.1 字符串 str

定义：一串字符，不可变（不能原地修改）。

  • ✅ 去空格后一定要接住：s = s.strip()，只写 s.strip() 等于没做
  • ✅ 用 "、".join(lst) 拼多个字符串，比用 + 更清晰也更快
  • ✅ join 的列表元素必须全是字符串，数字要先 str(x)（如 str(686)）
  • ⚠️ .replace(a, b) 默认替换全部匹配，不是只换第一个
  • ⚠️ .split() 不传参数 = 按任意空白切；.split(",") 按逗号切
  • ⚠️ .strip() 只去首尾，不去中间的字符
  • ❌ 别在循环里 s = s + x 拼长字符串（每次都在造新对象，很慢）

8.2 列表 list

定义：有顺序、可修改、可重复的序列。

  • ✅ 加一个用 append(x)，加一批用 extend([...])
  • ⚠️ append([1,2]) 会把整个列表塞进去，变成嵌套（[[1,2]]）
  • ✅ 删最后一个 pop()；删第一个 pop(0)；按值删 remove(x)
  • ✅ 复制一份用 lst[:] 或 lst.copy()
  • ⚠️ sort() / reverse() 是原地修改且返回 None → lst = lst.sort() 是错的！
  • ✅ 想要新列表用内置函数：sorted(lst)（排序）、list(reversed(lst))（倒序）
  • ⚠️ 边遍历边删除会错位（见 3.12），要么倒着删、要么遍历副本
  • ⚠️ lst = lst2 不复制，只多起了一个名字

8.3 元组 tuple

定义：有顺序、不能修改的序列。

  • ✅ 适合装"不该被改的常量数据" —— 本作业的 universities 就是
  • ⚠️ 只含一个元素的元组要加逗号：(1,) 是元组，(1) 只是数字！
  • ✅ 元组最适合解包：for name, city, line in universities:
  • ⚠️ "不能改"只到第一层：元组里如果放了列表，那个列表还是能改的
python
t = (1, [2, 3])
t[1].append(4)      # ✅ 可以！因为改的是里面的 list，不是元组本身

8.4 集合 set

定义：一堆不重复、无序的元素。

  • ✅ 去重：list(set(lst))（顺序会变，题目允许才算合格）
  • ✅ 查重：len(set(lst)) == len(lst)
  • ✅ 判断在不在：x in st（比在 list 里找快得多）
  • ⚠️ 空集合只能写 set() —— {} 是空字典！
  • ⚠️ 不能放 list / dict / set（不可哈希）
  • ⚠️ 不能用下标：st[0] 会报 TypeError
  • ✅ 交集 &、并集 |、差集 -

8.5 字典 dict

定义：键值对的集合，靠 key 找 value。

  • ✅ 取可能不存在的键，用 d.get(k, 默认值)；直接写 d[k] 取不到会 KeyError
  • ⚠️ k in d 判断的是键，不是值
  • ✅ 计数三连（背下来）：
python
if k in count:  count[k] += 1
else:           count[k] = 1
# 简写：count[k] = count.get(k, 0) + 1
  • ✅ 遍历方式：for k in d 得到键；for k, v in d.items() 得到键和值
  • ✅ Python 3.7+ 字典会保留插入顺序，但别把它当"有序容器"来用
  • ⚠️ 键必须可哈希（不能是 list）
  • ✅ 合并用 d.update(other)

8.6 range 与循环

  • ✅ range(n) 是 0 … n-1（左闭右开）
  • ✅ 倒序黄金公式：for i in range(len(x) - 1, -1, -1)
  • ✅ 只想遍历元素：for x in lst（不需要下标就别用 range）
  • ✅ 既要下标又要元素：for i, x in enumerate(lst)
  • ✅ 同时遍历两个列表：for a, b in zip(list1, list2)
  • ⚠️ 循环变量在循环结束后仍然存在（坑 3 的 x 就是这么来的）
  • ⚠️ while 里的条件必须有机会变假，否则死循环
  • ⚠️ 循环里别一边遍历一边删元素

8.7 函数与返回值

  • ✅ 函数的输入是参数，输出是 return；只认参数、不认全局
  • ✅ 多返回值其实就是返回元组，调用时解包：

challenge, safe, not_rec = analyze_student(...)

  • ✅ 函数可以当参数传（回调）：progress_function(0.05, final_analysis)
  • ✅ 函数名加括号才是调用：final_analysis 是动作，final_analysis() 是执行
  • ⚠️ 没有 return 就返回 None（坑 3）
  • ⚠️ 函数里给变量赋值不会改到全局，除非写 global（不推荐）
  • ⚠️ 默认参数别用可变对象（lst=[] 会被所有调用共享，见 3.16）
  • ✅ 函数开头写 docstring：做什么 / 参数 / 返回什么

8.8 输出与格式

  • ✅ 拼多行报告用 "\n".join(行列表)，比反复 += 干净
  • ✅ f-string 常用格式：f"{x:3d}"（右对齐 3 位）、f"{p:.1f}"（一位小数）
  • ✅ 进度条"原地刷新"三件套：\r（回车）+ end=""（不换行）+ flush=True（立刻输出）
  • ⚠️ print() 不传参数只输出一个空行
  • ⚠️ 中文/符号在不同终端宽度可能对不齐，别指望用空格硬对

8.9 调试与排错

  • ✅ 读报错从下往上看：最后一行是类型，倒数第二行是文件和行号
  • ✅ 不确定类型就 print(type(x))
  • ✅ 想看清空格/换行用 print(repr(x))（strip() 有没有生效一测就知道）
  • ✅ 二分定位：把确定没问题的部分先注释掉，缩小范围
  • ✅ 手推表格：把每一步的变量值写下来（坑 2 就是这么找到的）
  • ⚠️ "不报错但结果错"最危险（坑 1、坑 6），只能靠对照题目的"目标效果"发现
  • ⚠️ 变量名拼错导致 NameError 时，先看是不是拼写问题
