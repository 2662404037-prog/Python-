一、办公自动化：把重复工作交出去

1.1 openpyxl —— 用代码写 Excel

🧠 人话：它能让程序生成 Excel —— 有表头、有格式、有公式、有多个 sheet。

🏠 生活比喻：你手工在 Excel 里敲一天，它能一秒敲一万行。

🔧 常用工具

工具 干什么 典型写法
Workbook() 新建工作簿 wb = Workbook()
wb.active 拿到当前工作表 ws = wb.active
ws.append([...]) 追加一行（最常用） ws.append(["张三", 686])
ws["A1"] = 值 按单元格写 也能写公式 "=SUM(B2:B3)"
Font(bold=True) 加粗 表头常用
PatternFill("solid", fgColor="4F81BD") 底色 表头美化
ws.column_dimensions["A"].width = 14 调列宽 中文不挤
ws.freeze_panes = "A2" 冻结首行 滚动表头不动
load_workbook("x.xlsx") 读文件 ws.iter_rows(values_only=True)
wb.save("x.xlsx") 保存 别忘

🚀 上手

python
from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill

wb = Workbook(); ws = wb.active; ws.title = "成绩"
ws.append(["姓名", "分数"])                       # 表头
for n, s in [("张三", 686), ("李四", 655)]:
    ws.append([n, s])

ws["A1"].font = Font(bold=True, color="FFFFFF")   # 表头白字
ws["A1"].fill = PatternFill("solid", fgColor="4F81BD")
ws.column_dimensions["A"].width = 14
ws.freeze_panes = "A2"                            # 冻结首行
wb.save("成绩表.xlsx")
print("生成成功")
💡 小白提示：pip install openpyxl。它只支持 .xlsx，老的 .xls 要用 xlrd。

1.4 pyautogui —— 没有 API 的软件，就模拟鼠标

🧠 人话：程序替你动鼠标、敲键盘。给那些"没有接口、只能手动点"的软件做自动化。

🔧 常用工具

工具 干什么 典型写法
pyautogui.position() 当前鼠标坐标 先用它量坐标
pyautogui.moveTo(x, y, duration=0.5) 移动 duration 是动画时长
pyautogui.click(x, y) 点击 不传坐标就点当前位置
pyautogui.write("abc", interval=0.05) 打字 interval 防漏字
pyautogui.hotkey("ctrl", "s") 组合键 Ctrl+S、Ctrl+C
pyautogui.screenshot("x.png") 截图 存证/找图
locateCenterOnScreen("btn.png") 找图（比坐标稳） 配 confidence=0.9
pyautogui.FAILSAFE 紧急中止 鼠标甩到左上角
python
import pyautogui, time

time.sleep(3)                                  # 给自己 3 秒切窗口
pyautogui.click(400, 300)                      # 点一下
pyautogui.write("hello", interval=0.05)        # 打字
pyautogui.hotkey("ctrl", "s")                  # 保存
⚠️ 两条保命提示：① 鼠标快速甩到屏幕左上角可紧急停止；② 屏幕缩放会改变坐标，能用"找图"就别写死坐标。

1.5 schedule —— 让它每天自己跑

python
import schedule, time

def job():
    print("该交周报了！")

schedule.every().day.at("20:00").do(job)          # 每天 20:00
schedule.every(10).minutes.do(job)                # 每 10 分钟
schedule.every().monday.at("09:00").do(job)       # 每周一 9:00

while True:                                        # 需要程序一直挂着
    schedule.run_pending()
    time.sleep(1)
💡 Windows 上更省事的做法：直接把脚本丢进「启动」文件夹，或用系统自带的任务计划程序。

🎯 实战：一个"自动生成周报"脚本（完整可跑）

场景：从数据生成 Excel + Word 两份文件。

python
from openpyxl import Workbook
from docx import Document
from datetime import datetime

data = [("周一", 8), ("周二", 7.5), ("周三", 9), ("周四", 8.5), ("周五", 7)]
total = sum(h for _, h in data)

# ① 出 Excel
wb = Workbook(); ws = wb.active; ws.title = "工时"
ws.append(["日期", "工时"])
for d, h in data:
    ws.append([d, h])
ws.append(["合计", total])
wb.save("周报.xlsx")

# ② 出 Word
doc = Document()
doc.add_heading("本周工作周报", level=1)
doc.add_paragraph("生成时间：" + datetime.now().strftime("%Y-%m-%d %H:%M"))
t = doc.add_table(rows=1, cols=2); t.style = "Table Grid"
t.rows[0].cells[0].text = "日期"; t.rows[0].cells[1].text = "工时"
for d, h in data:
    c = t.add_row().cells; c[0].text, c[1].text = d, str(h)
doc.add_paragraph("本周共 %.1f 小时，平均每天 %.1f 小时。" % (total, total / len(data)))
doc.save("周报.docx")

print("已生成 周报.xlsx 和 周报.docx，总工时:", total)

运行结果：

text
已生成 周报.xlsx 和 周报.docx，总工时: 40.0

这类脚本的价值：写一次，以后每周点一下就行。 这就是"自动化"最朴素也最实用的形态。

2.1 loguru —— 别再用 print 调试了

🧠 人话：一行搞定漂亮的日志：有时间、有级别、能落盘、出错自动带完整堆栈。

🔧 常用工具

工具 干什么 典型写法
logger.add("run.log") 日志写文件 加 rotation="10 MB" 自动切割
logger.info / .warning / .error 分级日志 按重要性打
logger.success("完成") 成功（绿色的） 好看
logger.exception("出错了") 自动附完整堆栈 写在 except 里
logger.debug(变量) 调试信息 配 level="DEBUG"
python
from loguru import logger

logger.add("run.log", rotation="10 MB", encoding="utf-8")
logger.info("程序启动")

try:
    1 / 0
except ZeroDivisionError:
    logger.exception("这里出错了")     # 日志文件里有完整调用栈

2.3 pytest —— "敢改代码"的底气

🧠 人话：给函数写几行断言，改完代码一键验证有没有改坏别的地方。

🔧 常用工具

工具 干什么 典型写法
文件名 test_*.py 约定 pytest 只认这个命名
def test_xxx(): 一个测试 函数名也要 test_ 开头
assert 表达式 断言 失败就报错
pytest.raises(异常) 断言"这里该报错" 测异常分支
@pytest.mark.parametrize 一次测多组数据 表驱动
命令行 pytest -v 跑测试 -k 名字 只跑部分
python
# test_score.py
def analyze(score, line):
    if score >= line: return "稳妥"
    if score >= line - 10: return "冲刺"
    return "暂不推荐"

def test_safe():     assert analyze(686, 680) == "稳妥"
def test_challenge(): assert analyze(686, 690) == "冲刺"

import pytest
@pytest.mark.parametrize("s,l,e", [(700,700,"稳妥"), (695,700,"冲刺")])
def test_more(s, l, e): assert analyze(s, l) == e
bash
pytest -v

2.6 配置与密钥：.env 的正确姿势

🧠 人话：密码、API Key 绝不能写死在代码里。放在 .env 文件里，用 python-dotenv 读。

python
import os
from dotenv import load_dotenv

load_dotenv()                          # 读取同目录的 .env
key = os.getenv("OPENAI_API_KEY")       # .env 里写 OPENAI_API_KEY=sk-xxxxx
print("读到密钥:", key[:6] + "…")

🔧 常用工具

工具 干什么 典型写法
load_dotenv() 读 .env 程序开头调一次
os.getenv("KEY", 默认值) 取配置 给默认值更稳
yaml.safe_load(文件) 读 YAML 配置 复杂配置用它
json.dumps(d, ensure_ascii=False) 存 JSON（中文不转义） 存数据
⚠️ 务必把 .env 加进 .gitignore！否则推送到 GitHub 后，密钥几分钟内就可能被盗用。

五、新手最容易踩的 12 个坑（速查）

# 坑 正确做法
1 ModuleNotFoundError 就怀疑代码 先 pip install，并确认在当前虚拟环境里
2 requests 不加 timeout 永远加，否则永久卡住
3 网页中文乱码 r.encoding = r.apparent_encoding
4 select_one 返回 None 就崩 先 if tag: 再取值
5 抓到的链接打不开 urljoin(当前页, href)
6 用 f-string 拼 SQL 永远用 ? 占位符
7 用 MD5 存密码 用 bcrypt
8 用 random 生成 Token 用 secrets
9 API Key 写死在代码里 .env + python-dotenv + .gitignore
10 matplotlib 中文变方框 设 font.sans-serif
11 lst = lst.sort() 变成 None sort() 原地改；要新表用 sorted()
12 所有代码堆在一个文件里 用函数拆开，一个函数干一件事
